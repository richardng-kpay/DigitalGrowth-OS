# Knowledge index

Canonical catalog for the Knowledge wiki. Update on every `/wiki-ingest`. Run `/wiki-maintain` weekly.

**Lifecycle states:** `Active` (updated ≤ 30 days) · `Candidate` (under investigation) · `Archive` (dormant 90+ days)

Every row carries a provenance tag from `Knowledge/Reference/provenance-tags.md`. Synthesis across
pages lives in `Knowledge/overview.md`; the append-only operation history lives in `Knowledge/log.md`.
